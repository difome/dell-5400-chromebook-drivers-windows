# Установка драйвера клавиатуры Sarien на Windows 10

## Экспериментальная ветка с двумя режимами

В ветке `experimental/top-row-modes` сохранены два отдельных ZIP:

- `ActionKeys` — верхний ряд работает как кнопки Chromebook; кнопка снимка
  отправляет Windows-код Print Screen;
- `FunctionKeys` — позиции верхнего ряда работают как F1-F9 и F12, а F10/F11
  и так приходят как обычные функциональные клавиши.

Fn обрабатывается внутри EC и не виден драйверу Windows, поэтому режим
`FunctionKeys` действует постоянно. Одновременно устанавливайте только один
вариант. Для смены режима распакуйте другой ZIP, запустите находящийся внутри
`INSTALL-KEYBOARD.ps1` от имени администратора и перезагрузите Windows.

Этот тестовый драйвер предназначен только для Dell Latitude 5400 Chromebook
(Google Sarien) с Windows 10 x64. На других компьютерах его не устанавливать.

## Что понадобится

- внешняя USB-клавиатура на случай, если встроенная клавиатура временно не
  заработает;
- права администратора;
- распакованный архив драйвера;
- отключённый BitLocker либо сохранённый ключ восстановления BitLocker.

На Sarien с coreboot отдельной настройки Secure Boot обычно нет. Установщик
остановится только в том случае, если сама Windows явно сообщит, что Secure
Boot включён.

## 1. Включение тестового режима Windows

Откройте PowerShell или командную строку от имени администратора и выполните:

```powershell
bcdedit /set testsigning on
```

После сообщения об успешном выполнении перезагрузите компьютер.

После перезагрузки в углу рабочего стола может появиться надпись `Test Mode` —
для тестового драйвера это нормально.

## 2. Распаковка

Полностью распакуйте ZIP в обычную папку. Не запускайте установку прямо из
окна архиватора.

## 3. Диагностика до установки

Откройте PowerShell от имени администратора, перейдите в распакованную папку и
выполните:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\collect-diagnostics.ps1
```

Скрипт создаст ZIP с диагностикой. Сохраните его: он понадобится, если драйвер
не увидит клавиатуру.

## 4. Установка

В том же окне PowerShell выполните:

```powershell
.\install-test.ps1
```

Параметр `-AllowExistingI8042` не добавляйте. Он отключает защиту от одновременной
работы двух драйверов с портами клавиатуры.

После установки перезагрузите Windows, если `devcon` сообщит, что это требуется.

## 5. Проверка

Откройте Блокнот и по очереди проверьте:

1. буквы и цифры;
2. Shift, Ctrl и Alt;
3. Enter, Backspace и Delete;
4. стрелки, Page Up и Page Down;
5. верхний ряд Chromebook: назад, вперёд, обновить, яркость и громкость.

Если обычные клавиши работают, а часть верхнего ряда нет, это не авария — для
уточнения их кодов нужен отладочный лог конкретного Wilco EC.

## 6. Удаление

Чтобы удалить драйвер, откройте PowerShell от имени администратора в папке
драйвера и выполните:

```powershell
.\uninstall-test.ps1
```

Чтобы одновременно удалить установленный тестовый сертификат:

```powershell
.\uninstall-test.ps1 -RemoveTestCertificate
```

После удаления перезагрузите компьютер.

## Если Windows не загружается нормально

Подключите USB-клавиатуру, войдите в среду восстановления Windows и загрузите
безопасный режим. Затем удалите устройство `Sarien emulated i8042 keyboard
source` в Диспетчере устройств либо запустите `uninstall-test.ps1` от имени
администратора.

После завершения тестирования тестовый режим можно выключить:

```powershell
bcdedit /set testsigning off
```

Затем перезагрузите компьютер.

## Что прислать при проблеме

- ZIP, созданный `collect-diagnostics.ps1`;
- фотографию ошибки в Диспетчере устройств;
- описание того, какие клавиши работают;
- сообщения с префиксом `SarienI8042`, если использовался WinDbg или DbgView.
